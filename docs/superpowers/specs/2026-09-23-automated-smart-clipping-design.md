# Design Specification: Automated Smart-Clipping Core Module

**Date:** 2026-09-23  
**Status:** Draft / Ready for Implementation  
**Topic:** Automated Smart-Clipping with Word-Level Snapping, Narrative Structure (Hook, Core, Payoff), FFmpeg Splicing, and Removal of Compilation Feature  

---

## 1. Executive Summary & Goals

The Automated Smart-Clipping module provides an intelligent, end-to-end pipeline to transform long-form video into high-retention short clips. Unlike basic time-window cutting, this subsystem:
1. Extracts audio and generates full transcripts with precise **word-level timestamps** (using WhisperX / Faster-Whisper).
2. Uses an LLM to analyze narrative context and extract self-contained topics with a mandatory 3-part storytelling structure: **Hook** (attention grabber), **Pembahasan Inti / Core** (essential discussion), and **Payoff** (climax/resolution).
3. Executes **timestamp snapping** on each sub-segment to the nearest word boundary/speech pause to guarantee speech is never cut mid-syllable.
4. Uses **FFmpeg** to automatically slice and splice (concatenate) the selected segments into ready-to-publish short video files.
5. Surfaces this experimental feature directly beneath the pre-roll and post-roll controls in the WebUI.
6. Completely removes the legacy "Compile into single video" feature and all associated arguments/UI elements.

---

## 2. Architecture & Pipeline Data Flow

```
+---------------------------------------------------------------------------------+
|                                 Input Long Video                                |
+---------------------------------------------------------------------------------+
                                         |
                                         v
+---------------------------------------------------------------------------------+
| Step 1: Audio Extraction                                                        |
| - Fast extraction via FFmpeg (16kHz 16-bit mono PCM .wav)                       |
+---------------------------------------------------------------------------------+
                                         |
                                         v
+---------------------------------------------------------------------------------+
| Step 2: Full Word-Level Timestamped Transcription                               |
| - Runs WhisperX alignment pipeline (or loads existing input.json)              |
| - Produces word list: [{ "word": str, "start": float, "end": float, ... }]      |
+---------------------------------------------------------------------------------+
                                         |
                                         v
+---------------------------------------------------------------------------------+
| Step 3: LLM Narrative Context Analysis                                          |
| - Sends formatted transcript with time tags to LLM (Gemini / G4F / Local)       |
| - Extracts standalone topics with Hook, Core, and Payoff segments               |
+---------------------------------------------------------------------------------+
                                         |
                                         v
+---------------------------------------------------------------------------------+
| Step 4: Word-Level Boundary Snapping Engine                                     |
| - Snaps Hook start/end, Core start/end, Payoff start/end to exact word pauses   |
| - Applies safety margins (pre-word padding + post-word padding)                 |
| - Validates duration constraints & merges any overlapping sub-segments          |
+---------------------------------------------------------------------------------+
                                         |
                                         v
+---------------------------------------------------------------------------------+
| Step 5: FFmpeg Multi-Segment Slicing & Splicing                                 |
| - Cuts each segment cleanly (-ss ... -to ...)                                   |
| - Splices Hook + Core + Payoff into a single short video file                   |
| - Writes metadata & synchronized subtitle track for each clip                   |
+---------------------------------------------------------------------------------+
```

## 3. Core Module Specifications: `scripts/smart_clipping.py`

### 3.1 Audio Extraction
- **Function:** `extract_audio_for_transcription(video_path: str, output_wav_path: str) -> str`
- **Command:** `ffmpeg -y -i <video_path> -vn -acodec pcm_s16le -ar 16000 -ac 1 <output_wav_path>`
- Skips extraction if valid audio already exists or uses `input.mp4` directly.

### 3.2 Word-Level Timestamp Extraction
- **Function:** `extract_word_timestamps(project_folder: str, video_path: str) -> list[dict]`
- Reads `input.json` (generated by `transcribe_video.py` using WhisperX).
- Flattens segments into an indexed list of words:
  ```python
  {
      "word": str,
      "start": float, # seconds
      "end": float,   # seconds
      "score": float  # alignment confidence
  }
  ```
- If word timestamps are missing from raw Whisper output, gracefully falls back to segment-level boundaries with text interpolation.

### 3.3 LLM Narrative Topic Extraction
- **Prompt Structure:** Instructs LLM to act as an expert viral narrative editor.
- **Narrative Structure Contract:**
  ```json
  {
    "topics": [
      {
        "title": "Title of the topic",
        "rationale": "Why this narrative is engaging",
        "target_duration": 45.0,
        "segments": {
          "hook": {
            "start_time": 12.4,
            "end_time": 20.1,
            "text": "First few seconds hooking the viewer"
          },
          "core": {
            "start_time": 20.1,
            "end_time": 45.0,
            "text": "Core exposition or discussion"
          },
          "payoff": {
            "start_time": 75.2,
            "end_time": 90.0,
            "text": "The punchline, result, or takeaway"
          }
        }
      }
    ]
  }
  ```
- Supports both multi-segment splice (Hook, Core, Payoff from non-contiguous parts) and single-continuous topics.

### 3.4 Word-Level Boundary Snapping Engine
- **Function:** `snap_time_to_word_boundary(timestamp: float, words: list[dict], is_start: bool, window: float = 3.0, margin: float = 0.05) -> float`
- **Algorithm:**
  - Given raw timestamp $T$:
  - If `is_start=True`:
    - Candidate words: words where $|word.start - T| \le window$.
    - Find the word whose start is closest to $T$.
    - Snapped time = $\max(0, word.start - margin)$. This avoids truncating the first syllable/consonant.
  - If `is_start=False` (`end` time):
    - Candidate words: words where $|word.end - T| \le window$.
    - Find the word whose end is closest to $T$.
    - Snapped time = $word.end + margin$. This prevents cutting off the ending vowel/breath.
- **Deduplication and Ordering:**
  - If `hook.end` and `core.start` are separated by $< 0.3s$, merge them into a single continuous segment to avoid unnecessary cuts.
  - Ensure total duration conforms to user constraints (`min_duration`, `max_duration`).

### 3.5 FFmpeg Splicing Engine
- **Function:** `splice_topic_segments(video_path: str, segments: list[tuple[float, float]], output_path: str) -> str`
- For single segment: Direct cut using fast re-encode for sample accuracy:
  `ffmpeg -y -ss {start} -to {end} -i {video_path} -c:v libx264 -crf 18 -preset fast -c:a aac -b:a 192k {output_path}`
- For multi-segment:
  1. Cut each sub-segment to a temporary directory in project folder.
  2. Write concat list file `concat_list.txt`:
     ```
     file 'subseg_0.mp4'
     file 'subseg_1.mp4'
     file 'subseg_2.mp4'
     ```
  3. Concatenate losslessly via demuxer:
     `ffmpeg -y -f concat -safe 0 -i concat_list.txt -c copy {output_path}`
  4. Clean up temporary files.

## 4. WebUI & CLI Integration

### 4.1 UI Placement in `webui/app.py`
Placed directly under the `pre_roll_input` and `post_roll_input` row:
```python
with gr.Group():
    smart_clipping_enabled = gr.Checkbox(
        label=i18n("Automated Smart-Clipping (Experimental)"),
        value=False
    )
    with gr.Row(visible=False) as smart_clipping_options:
        smart_clipping_mode = gr.Dropdown(
            choices=[
                ("Multi-Segment Splice (Hook + Core + Payoff)", "splice"),
                ("Single Continuous Topic", "continuous")
            ],
            value="splice",
            label=i18n("Narrative Structure Mode")
        )
        smart_snap_margin = gr.Number(
            label=i18n("Word Snap Margin (s)"),
            value=0.05,
            precision=2
        )
```
- Event listener to toggle visibility when `smart_clipping_enabled` is checked.

### 4.2 CLI Options in `main_improved.py`
Add:
- `--smart-clipping`: Flag to enable automated smart clipping mode.
- `--smart-clipping-mode`: Choices `splice` or `continuous` (default `splice`).
- `--smart-snap-margin`: Float, default `0.05`.

## 5. Removal of Legacy Compilation Feature

The following legacy components are completely removed:
1. **CLI Arguments in `main_improved.py`:**
   - Remove `--compile`
   - Remove `--crossfade`
   - Remove `--fade-to-black`
   - Remove `--segment-order`
   - Remove compilation execution block (lines ~927-947).
2. **WebUI in `webui/app.py`:**
   - Remove `compile_mode_input`, `crossfade_duration_input`, `segment_order_input`.
   - Remove change event listeners for `compile_mode_input`.
   - Remove arguments from `run_viral_cutter` function signature and CLI invocation.
3. **Project Export & Scripts:**
   - Remove `compilation.mp4` / `compilation.srt` references from `webui/project_export.py`.
   - Remove unused import of `compile_segments` from `main_improved.py`.
   - Mark `scripts/compile_segments.py` as deprecated or remove.

   - Test word-level snapping with artificial word timestamp data:
     - Verify timestamps snap to word start/end with margins.
     - Verify no mid-word cuts occur.
     - Verify overlapping/adjacent segment merging.
   - Test LLM response parser:
     - Verify robust parsing of JSON containing Hook, Core, Payoff structures.
     - Verify fallback behavior if structure is partially missing.
   - Test FFmpeg splicing script builder.
2. **Verification of Removal:**
   - Run `python main_improved.py --help` to ensure `--compile` is cleanly absent.
   - Run syntax and import checks on `webui/app.py` and `main_improved.py`.
3. **End-to-End Smoke Test:**
   - Verify smart clipping pipeline with mock transcript and synthetic test video.
